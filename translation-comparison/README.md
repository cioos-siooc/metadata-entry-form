# Translation Comparison Tool

Compares AWS Translate translations (from existing Firebase records) against Cohere translations to evaluate translation quality across different models and prompts.

## Prerequisites

- **COHERE_API_KEY** environment variable set
- **Firebase export** JSON file at `../cioos-metadata-form-dev-258dc-default-rtdb-export (2).json`
- **Prompt template** synced from cioos-commons at `../firebase-functions/functions/translation-prompt-template.txt`

## Setup

```bash
cd translation-comparison
npm install
```

## Running a Comparison

```bash
# Default run name: {model}-{prompt-hash}
COHERE_API_KEY=your-key node compare.js

# Name a run explicitly
COHERE_API_KEY=your-key node compare.js --run v2-ocean-specialist

# Use production-tier rate limits
COHERE_API_KEY=your-key node compare.js --production
```

Results are saved to `results/<run-name>/` containing:

- `intermediate.json` — raw translation results
- `text-cache.json` — deduplication cache by content hash
- `run-meta.json` — run metadata (model, timestamp, counts)

## Generating a Report

```bash
# Report for a specific run
node report.js --run v2-ocean-specialist

# Report for the latest run
node report.js
```

Generates `index.html` and `data.json` in the run directory. View with:

```bash
npx serve results/<run-name>
```

## Comparing Multiple Runs

```bash
node compare-runs.js <run1> <run2> [run3...]
```

Example:

```bash
node compare-runs.js command-a-03-2025-abc1234 command-a-translate-08-2025-def5678
```

Generates a side-by-side HTML comparison at `results/comparison-<run1>-vs-<run2>.html` showing:

- Aggregate stats per run
- Filter by identical/different translations
- Source text alongside each run's translation

## Directory Structure

```
results/
  command-a-03-2025-abc1234/    # auto-named: model + prompt hash
    intermediate.json
    text-cache.json
    run-meta.json
    index.html                   # generated by report.js
    data.json                    # generated by report.js
  v2-ocean-specialist/           # explicitly named run
    ...
  comparison-run1-vs-run2.html   # generated by compare-runs.js
```
